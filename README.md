# Vale dos Ipês: protótipo (Etapa 3)

Protótipo navegável de média fidelidade de um app de turismo e lazer de Lavras (MG), feito para o projeto prático da disciplina Interação Humano-Computador da UFLA (2026/2).

Dupla: Ramon Fontana de Souza e João Paulo Souza Selvati.

## Tarefas do teste de usabilidade

1. Encontrar um restaurante aberto agora e ver como chegar.
2. Encontrar a Feira de Sabores de Lavras e ativar o aviso do evento.
3. Encontrar uma rota de bike curta e fácil, ver distância e paradas e salvar nos favoritos.

No protótipo, o horário é fixo (sábado, 19:30) e o usuário é sempre "Usuário 1", para que todos os participantes vejam o mesmo conteúdo.

## Como rodar

É um único arquivo `index.html` (HTML, CSS e JavaScript, sem dependências). Basta abrir no navegador ou publicar como site estático (Vercel).

Dados técnicos das rotas: relatório da Fase 3 da consultoria ADDTUR (2024). Horários, preços e eventos são dados de exemplo para o teste.
